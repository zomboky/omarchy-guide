# Omarchy — guide de mise en route (français)

Un guide PDF pédagogique de **mise en place d'Omarchy 4 après l'installation**, écrit
pour un utilisateur débutant sous Linux.

- **Le guide :** [`guide-omarchy/guide-omarchy-fr.pdf`](guide-omarchy/guide-omarchy-fr.pdf)
  — 138 pages, 52 chapitres et 4 annexes, 29 captures d'écran.
- **Les sources et le script de génération :** [`guide-omarchy/`](guide-omarchy/)

Tout le contenu technique provient du manuel officiel <https://omarchy.org/manual/>,
dont les 51 chapitres ont été relus un à un ; chaque chapitre du guide cite ses sources.
